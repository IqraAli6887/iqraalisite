# Iqra Ali Academic Website

A GitHub Pages-ready academic website for Iqra Ali.

This version follows the structure of a traditional academic researcher homepage:

- Profile header
- About / biography
- Activities and news
- Research interests
- Education
- Experience
- Publications
- Research projects
- Academic service
- Presentations
- Contact

## Upload to your existing repository

Repository:

```text
https://github.com/IqraAli6887/iqraalisite
```

Replace the current root files with the files from this folder:

```text
index.html
styles.css
script.js
assets/
README.md
```

Do **not** upload the parent folder itself.

Your repository root should look like:

```text
iqraalisite/
├── assets/
│   └── favicon.svg
├── index.html
├── styles.css
├── script.js
└── README.md
```

Then GitHub Pages should remain configured as:

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

Website:

```text
https://iqraali6887.github.io/iqraalisite/
```

## Profile photograph

The website is already configured to use:

```text
assets/iqra.jpeg
```

Place your `iqra.jpeg` image inside the `assets` folder before uploading the site to GitHub.

The repository should contain:

```text
assets/
├── favicon.svg
└── iqra.jpeg
```
